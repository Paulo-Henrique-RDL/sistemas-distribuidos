| 1 | [atv1-socket-tcp](atv1-socket-tcp/) | Comunicação cliente-servidor com sockets TCP |

## Requisitos

- JDK 17 ou superior (`java -version` para conferir)

## Organização

Cada atividade fica em sua própria pasta, no formato `atvN-tema`, com:

```
atvN-tema/
├── README.md    o que a atividade faz, protocolo e como executar
└── src/         código-fonte Java
```

Os arquivos compilados (`bin/`, `*.class`) não são versionados.
