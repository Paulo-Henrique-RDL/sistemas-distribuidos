o item guarda o preco praticado na data da compra, e por isso o historico nao
muda quando o catalogo reajusta.

-------------------------------------------------------------------------------
ESCRITA: ao abrir um pedido, o preco vem do catalogo, nao de quem chama.

$ curl -X POST http://localhost:8300/pedidos \
    -d '{"clienteId":4,"itens":[{"produtoId":3,"quantidade":1},{"produtoId":4,"quantidade":2}]}'

{
    "id": 5,
    "cliente": {
        "id": 4,
        "nome": "Distribuidora Sul",
        "documento": "23.456.789/0001-01",
        "email": "pedidos@distsul.com.br"
    },
    "situacao": "CRIADO",
    "valorTotal": 1268.8,
    "dataPedido": "2026-10-14T00:30:46.18922",
    "itens": [
        {
            "id": 9,
            "produtoId": 3,
            "sku": "MON-003",
            "nomeProduto": "Monitor 24 polegadas",
            "quantidade": 1,
            "precoUnitario": 949.0,
            "subtotal": 949.0
        },
        {
            "id": 10,
            "produtoId": 4,
            "sku": "HEA-004",
            "nomeProduto": "Headset com microfone",
            "quantidade": 2,
            "precoUnitario": 159.9,
            "subtotal": 319.8
        }
    ]
}

A requisicao informou apenas produto e quantidade. O monitor entrou a 949,00
e o headset a 159,90 porque foi isso que o catalogo-service respondeu, e o
total foi calculado a partir dai.
